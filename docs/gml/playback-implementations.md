# Drawing GML: sample playback code

Community implementations for rendering GML, by platform. Most are from the
project's early years and are kept as the historical record. Links checked on
2026-09-01; those whose host no longer answers are marked offline.

## C++ (openFrameworks)

- [Graffiti Analysis](http://graffitianalysis.com/downloads/) by Evan Roth and Chris Sugrue
- [LASER Tag](http://muonics.net/blog/index.php?postid=26) *(offline)* by Theo Watson and Zach Lieberman
- [EyeWriter](http://eyewriter.org) by all of the above plus Tony Quan (Tempt1) and James Powderly

## Javascript

- [Canvasplayer](http://jamiedubs.com/canvasplayer) with Processing.js, by Jamie Wilkinson
- [SVG-WOW Graffitis](http://svg-wow.org/graffitis/graffitis.xhtml) by Vincent Hardy
- [GML Canvas Recorder](http://codingwithattitude.net/gml/gml-drawer.html) *(offline)* (capture) by Laurent Van Basseliere
- [Webmarker](http://webmarker.me), a Firefox addon by Tobias Leingruber, Jamie Wilkinson and Greg Leuch (capture and playback)

## Processing (Java)

- [Obama GML Playa](http://graffitimarkuplanguage.com/obama-gml-playa/) *(offline)* by Golan Levin and Jerome St Clair
- [GML4U](http://wiki.github.com/01010101/GML4U/) *(offline)*, a complete GML processing library by Jerome St Clair
- [Graffiti Viscosity](http://www.pixelnerve.com/v/2010/09/07/gml-viscosity/) *(offline)* by Victor Martins
- [Robotagger GML to DXF converter](http://fffff.at/files/2010/01/GML_to_DXF-100109a.zip) by Golan Levin

## Flash (ActionScript)

- [000book Flash Player](http://github.com/jamiew/gml-flashplayer) by Todd Vanderlin, an embeddable player with time-scrubbing
- [3D Stylized Graffiti Rendering](http://kode80.com/2010/01/08/stylized-graffiti-rendering/) *(offline)* by Ben Hopkins (kode80), AS3
- [Okr](http://toki-woki.net/p/Okr/) by TokiWoki, with drips, stroke controls and more

## iPhone (openFrameworks / ofxiPhone)

- [DustTag](http://graffitianalysis.com/iphone/)
- [FatTag Deluxe](http://fffff.at/fattag-deluxe-katsu-edition/)
