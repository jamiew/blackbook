# Drawing GML with Javascript and JSON

There is a simple demo of rendering GML in the browser using Javascript and
HTML5 canvas via [Processing.js](http://processingjs.org/). GML data is loaded
from 000000book using a JSON callback, sometimes called GSON.

- Demo: <http://jamiedubs.com/canvasplayer>
- Code: <http://github.com/jamiew/canvasplayer>
